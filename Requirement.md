Assignment 2 — AI Application Engineer

Build an intelligent API router that selects the most appropriate LLM provider based on the user's query.

The application should expose a single API endpoint and automatically route requests to different providers depending on the task.

Examples include:
- Coding
- Writing
- Summarisation
- Translation
- General reasoning

Requirements
- Python
- Build a single API endpoint that accepts a user query.
- Intelligently route the request to the most appropriate LLM.
- Use multiple LLM providers.
- Design the system to be easily extensible for adding new providers.
- Store configuration using environment variables.
- Submit the GitHub repository and a README explaining your approach.

Notes 
- You are free to choose the LLM providers, APIs, SDKs, frameworks, and routing strategy.
- Use publicly accessible APIs or models suitable for development and evaluation.
- Clearly explain your routing logic and architectural decisions in the README.
